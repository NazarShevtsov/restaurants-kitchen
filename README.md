# Menu Management

Menu Management is a web application that allows users to manage restaurant employees and products. It provides functionality for adding, editing, viewing, and deleting employee and product records.

The application was built using Django and HTML templates.

## Features

- Manage restaurant employees (cooks).
- Manage menu items (dishes).
- Manage dish types and categories.
- Add, edit, view, and delete records.
- View statistics about cooks and dishes.
